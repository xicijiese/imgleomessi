- 梳理 Web 前台页面清单，包括主入口菜单、子页面和每个子页面负责范围。
- 梳理 Filament 后台页面清单，包括主入口菜单、子菜单和每个子菜单负责范围。
- 标注每个页面的开发优先级。
- 细化每个 P0 页面入口、用户角色、核心模块、字段/展示内容、操作、状态边界和验收标准。
- 同步更新 docs/ui/page-map.md、docs/project/development-progress.md 和必要的数据模型说明；不新增说明类文档。
- 确认后续开发节奏：每个切片必须先一次性确认字段、按钮、筛选、排序、状态、权限、验收标准、交互方式和 UI/UX 风格，再开发、验证和收口。

- 不接 COS、数据万象或搜索引擎。
