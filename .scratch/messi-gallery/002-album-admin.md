# 相册后台管理

## 背景

分类与标签字典已经能在后台维护。图片批量上传前，需要先能创建相册，并为相册选择 8 个固定主分类下的子分类，其中生涯阶段、年份、场景为必选。

## 用户价值

管理员可以先搭建事件相册或专题相册，后续上传图片时直接选择相册并继承相册分类。

## 范围

- albums 表。
- album_category 表。
- album_photo 表。
- Album 模型。
- Filament 相册管理资源。
- Feature Test。

## 不做什么

- 不做图片上传。
- 不创建 photos 表。
- 不接 COS。
- 不做前台相册页。
- 不做相似图去重。

## 验收标准

- [x] 后台可访问相册管理页。
- [x] 相册默认状态为 draft。
- [x] 相册必须从 3 个必选主分类中各选择 1 个子分类，其他 5 个主分类可选。
- [x] album_photo 支持同一个 photo_id 关联多个相册。
- [x] 测试通过。

## 测试要求

运行 php artisan test。

## 依赖

分类与标签后台字典管理。
