## 进度口径

`docs/project/development-progress.md` 是当前路线、真实进度、当前唯一开发入口和下一步计划的唯一事实源。本目录只记录本地任务，不单独决定开发顺序；如果任务文件与主进度文档冲突，先同步主进度文档，再修正任务文件。

未开发功能清单以 `docs/project/development-progress.md` 的当前未开发功能总览为准；本目录的历史任务草案不能作为“未开始”的判断依据。

开发节奏固定为：确认稿 -> 用户确认 -> 开发 -> 测试/构建 -> 文档收口 -> 下一切片确认稿。当前本地代码已完成 P0 核心闭环、P1-1 至 P1-15 基础切片、时间轴/资料维度聚合/搜索运营、图片处理基础链路、分类删除保护、档案共建者阶段 2A 与 2B，以及项目所需的管理员用户治理与头像。阶段 2A/2B 已通过专项测试和全量回归，生产迁移与生产验收已有记录；最新的收藏/点赞 CSRF 会话修复已进入代码基线，但生产需按主进度文档重新回归。智能标签当前停用，仅保留历史兼容字段和历史任务数据；相似图与去重已于 2026-10-19 完成本地开发验收；真实支付本轮已授权开发，地址自动处理、渠道响应适配及资金联调待完成；外部搜索、小程序和生产运维增强后置。动态用户组、多角色并存、细粒度资源权限等企业级权限能力不属于本项目需求。
