# Messi Gallery 本地任务区

本目录用于开发初期的本地 Markdown 任务追踪。后续可迁移到 GitHub Issues。

## 进度口径

`docs/project/development-progress.md` 是当前路线、真实进度、当前唯一开发入口和下一步计划的唯一事实源。本目录只记录本地任务，不单独决定开发顺序；如果任务文件与主进度文档冲突，先同步主进度文档，再修正任务文件。

未开发功能清单以 `docs/project/development-progress.md` 的“当前未开发功能总览（以此为准）”为准；本目录的旧任务草案不能作为“未开始”的判断依据。

开发节奏固定为：确认稿 -> 用户确认 -> 开发 -> 测试/构建 -> 文档收口 -> 下一切片确认稿。前台图库列表 /photos、前台搜索页 /search、前台相册列表 /albums、前台相册详情 /albums/{slug}、前台专题列表 /topics、前台专题详情 /topics/{slug} 和前台图片详情 /photos/{uuid} 基础实现已完成；P0 总体验收巡检和公开列表 / 搜索边界补漏已完成；P1-1 公开前台导航 UI/UX 对齐补漏和首页最新照片 / 专题空状态已完成；P1-2 账号基础与前台身份入口已完成；P1-3 站点说明与合规基础页已完成；P1-4 收藏 / 点赞 / 分享记录基础已完成；P1-5 图片评论与信息补充 / 纠错投稿已完成；P1-6 评论审核、举报、封禁与敏感词基础过滤已完成；P1-7 用户中心与通知中心已完成，账号设置入口补漏、设置页中文化和 settings 前台布局修复已收口；P1-8 互动统计与排行榜已完成；P1-9 运营守护者赞助闭环已完成；P1-10 勋章 / 成就基础已完成；P1-11 图片入库处理与后台重复图提示已完成；进入 P1-12 前的前台赞助导航、顶部“我的勋章”入口撤回、后台互动统计 UI 和入库处理语义收口已完成；P1-12 sitemap、SEO 基础优化已完成；P1-13 P1 阶段总体验收 / 补漏已完成；P1-14 第三方分享扩展已完成；P1-15 高级搜索与资料增强已完成；后续开发顺序确认稿、时间轴浏览开发前确认稿、球队 / 赛季 / 对手聚合开发前确认稿、公开用户个人主页开发前确认稿、对手聚合数据模型开发前确认稿和搜索建议 / 热门搜索 / 后台搜索运营配置开发前确认稿已确认，时间轴浏览、球队 / 生涯阶段聚合、赛季聚合、公开用户个人主页、对手聚合和搜索运营已完成；外部搜索引擎必要性评估已完成并建议后置；腾讯云数据万象基础处理能力首个派生图切片已完成，包含 COS + 数据万象条件入队、展示图/缩略图生成、失败记录、有限重试和人工重试；相似图首个后台辅助切片和 OCR 后台手动处理切片已完成；上传后状态选择、基础处理完成后自动发布、OCR / 智能标签自动任务开关和归档恢复已完成；当前唯一开发入口为档案共建者与用户管理完整闭环；生产队列失败恢复、批次统计、上线前检查和 Supervisor 部署说明已完成，但生产环境测试必须等档案共建者与用户管理全部开发完成后统一进行。COS 临时读写真实验证已通过，当前 6 张业务原图已完成派生图、SHA-256、智能标签和相似候选真实验证；图片质量评分明确不纳入项目。存储后台开关、COS 配置边界、存储检测和图片处理队列已完成。关注、私信、动态流、真实支付、小程序或其他未确认新切片继续后置。

## 第一批建议任务原始草案

1. `001-initialize-laravel-filament.md`：初始化 Laravel + Filament 项目。
2. `002-core-gallery-schema.md`：建立图库核心数据库迁移。
3. `003-admin-photo-upload.md`：后台图片上传到可配置存储，本地存储和腾讯云 COS 两种方式都可切换。
4. `004-public-gallery-browse.md`：前台图库浏览。
5. `005-basic-search-filters.md`：基础搜索和筛选。
6. `006-user-auth-favorites.md`：用户登录和收藏。
7. `007-comments-moderation.md`：评论与审核。
8. `008-sponsorship-orders.md`：赞助订单和支付准备。

测试图片统一放在 .scratch/messi-gallery/test-images/。该目录只作为本地测试素材投放区，用于后续构造相册、专题、最新照片、图片详情、搜索和空状态/有数据状态验收；真实图片文件不进入版本控制。

运行 php artisan db:seed --class=LocalGalleryDemoSeeder 可根据测试图片生成或刷新本地前台演示数据，包括测试图片、相册、首页头图、专题配置、4 个模拟用户、若干已发布评论 / 待审核纠错记录，以及点赞、收藏、分享排行榜测试数据、4 个模拟运营守护者赞助订单、用户勋章记录和图片基础处理任务结果；对手和搜索运营演示数据后续如需要可单独确认补充；重复运行时不会反复改动已存在测试图片的 uuid。
