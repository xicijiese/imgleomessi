# Messi Gallery 本地任务区

本目录用于开发初期的本地 Markdown 任务追踪。后续可迁移到 GitHub Issues。

## 第一批建议任务

1. `001-initialize-laravel-filament.md`：初始化 Laravel + Filament 项目。
2. `002-core-gallery-schema.md`：建立图库核心数据库迁移。
3. `003-admin-photo-upload.md`：后台图片上传到 COS。
4. `004-public-gallery-browse.md`：前台图库浏览。
5. `005-basic-search-filters.md`：基础搜索和筛选。
6. `006-user-auth-favorites.md`：用户登录和收藏。
7. `007-comments-moderation.md`：评论与审核。
8. `008-sponsorship-orders.md`：赞助订单和支付准备。
