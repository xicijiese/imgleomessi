# 用户管理与档案共建者：阶段 2A、阶段 2B、管理员治理与头像

## 状态

阶段 2A、阶段 2B 以及管理员用户治理与用户头像已完成本地代码开发、专项测试、全量回归、前端类型检查和构建。

## 已完成范围

- 档案共建者只通过私域沟通产生，用户注册后由管理员在后台人工授予。
- contributor_profiles 保存共建者资料、授权角色快照、授予/撤销管理员、公开开关和撤销时间。
- `/admin/users` 支持授予、编辑和撤销共建者，并保留原有角色恢复规则。
- 管理员可维护展示名称、公开简介、贡献方向、展示顺序和公开开关。
- 普通用户被授予共建者时获得 editor 内容角色；撤销时只恢复本次授权产生的角色。
- `/settings/profile` 支持用户上传、替换和移除头像；`/admin/users` 支持管理员代维护头像。
- 头像只接受 JPG、PNG、WebP，最大 2MB，复用当前 local/COS 存储并只对外暴露解析后的公开 URL。
- 管理员可维护手机号和头像、调整 user/editor/admin 角色、启用/停用、封禁/解封、在编辑窗口直接重置登录密码和撤销全部会话；重置密码不发送邮件。
- 用户注册必须填写唯一的中国大陆 11 位手机号，已有用户可补充；用户管理支持批量启用、停用、封禁和解封；登录历史与管理员操作写入只读后台资源。
- 活动档案共建者必须先撤销后调整角色；最后一名有效管理员不能被降级。
- editor 只允许访问图片、相册、分类和标签资源；项目不引入动态用户组、细粒度资源 ACL 或其他企业级权限模型。
- `/supporters` 分开展示运营守护者与档案共建者，公开 payload 不泄露内部授权字段。
