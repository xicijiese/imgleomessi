## 已完成范围

- 档案共建者只通过私域沟通产生，用户注册后由管理员在后台人工授予。
- contributor_profiles 保存共建者资料、授权角色快照、授予/撤销管理员、公开开关和撤销时间。
- /admin/users 支持授予、编辑和撤销共建者。
- 管理员可维护展示名称、公开简介、贡献方向、展示顺序和公开开关。
- 普通用户被授予共建者时获得 editor 内容角色。
- 撤销时只恢复本次授权产生的角色；原有 editor 或 admin 不被降权。
- editor 只允许访问图片、相册、分类和标签资源。
- /supporters 分开展示金钱运营守护者与档案共建者。
- 前台只展示 active、未撤销且 is_public=true 的共建者。
- 前台公开 payload 只包含 id、展示名称、简介和贡献方向。
- 未公开、已撤销、已封禁或非正常账号不会出现在前台。
- 没有公开申请、审核、通过或取消申请流程。
- 来源整理在当前模型中通过图片来源字段和来源平台分类完成，没有独立 Source 后台资源。
