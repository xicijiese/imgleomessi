# PRD：梅西影像档案库

## 1. 问题陈述

梅西相关图片资料散落在社交平台、新闻网站、球迷账号和个人网盘中，存在时间不准、来源不清、分类混乱、重复图多、检索困难、高清版本难找等问题。用户想建立一个长期可维护的图库站，用于后续查阅、考古和中文球迷资料沉淀。

## 2. 产品定位

产品是“梅西影像档案库 + 轻社交 + 赞助支持”。

它不是官方站，不是后援会，不做版权内容售卖。赞助会员的含义是支持网站可持续维护，不是购买图片版权或解锁盗版图片。

## 3. 用户角色

| 角色 | 核心目标 | 主要权限 |
|---|---|---|
| 游客 | 浏览公开图片、相册和专题 | 浏览、搜索基础公开内容、分享公开页面；无需登录即可浏览全部公开内容 |
| 普通用户 | 收藏、互动、参与轻社交 | 登录、收藏、点赞、评论、举报、分享、佩戴勋章 |
| 支持者 | 赞助网站维护 | 普通用户权限、支持者徽章、支持者页展示、可选无广告/更高配额 |
| 编辑员 | 维护图片资料 | 上传图片、编辑图片元数据、管理相册、处理待考证资料 |
| 管理员 | 管理全站 | 用户、权限、订单、评论审核、系统设置、数据处理任务 |

## 4. 功能优先级

### P0：第一版必须完成

1. 管理员/编辑员后台登录。
2. 图片上传到可配置图片存储，本地存储和腾讯云 COS 两种方式都可切换；生产环境优先使用 COS/CDN。
3. 图片档案基础字段：标题、日期、相册、分类子项（含球队、赛事、赛季、年份等）、标签、来源、版权状态、审核状态。
4. 后台上传批次与批量整理：记录批量上传结果，支持逐图补资料和批量发布。
5. 相册管理：事件相册、专题相册、生涯阶段。
6. 前台图库浏览：首页、图库列表、搜索页、相册列表、相册详情、专题列表、专题详情、图片详情；首页包含“最新照片”模块。
7. 基础检索：关键词、相册、分类子项（含年份、球队、赛事等）、标签。
8. 图片缩略图与展示图。
9. 本地任务和开发规范文档。

### P1：第二阶段

1. 普通用户注册登录。
2. 收藏、点赞、评论、分享/转发记录；图片评论分为普通评论和图片信息补充/纠错两类。P1-4 已完成图片级收藏、点赞和分享记录基础；P1-5 已完成图片评论与信息补充/纠错提交和公开评论展示基础；P1-14 已完成图片详情页分享弹层、复制链接、系统分享、微博跳转分享、微信二维码引导和四类分享渠道记录；真实微信 JS-SDK / 第三方分享 API、分享海报生成、短链接、复杂社交动态流、后台互动管理、异常刷赞处理和排行榜管理放到后续独立切片。分享返利默认不做，除非后续重新立项并完成合规确认。
3. 评论审核、举报、封禁、敏感词基础过滤、互动统计排行榜；评论审核、举报、封禁与敏感词基础过滤已在 P1-6 完成基础切片，互动统计排行榜已在 P1-8 完成基础切片。
4. 支持者赞助：订单、支付回调、支持者身份、支持者页面。P1-9 已完成模拟赞助订单、模拟支付、支持者身份、支持者墙、个人赞助记录和后台赞助管理基础；真实支付 API、真实回调验签、退款、发票、续费提醒、优惠码、自定义金额和支付对账后续独立确认。
5. 勋章/成就：任务获得、管理员纪念日发放、用户佩戴勋章。P1-10 已完成基础获得规则、后台人工发放/撤销、用户佩戴和站内通知；纪念日自动发放、运营活动配置、公开勋章大厅和勋章排行榜后续独立确认。
6. 图片入库队列：EXIF、哈希、OCR。P1-11 已完成基础入库任务与 metadata/hash 处理；OCR 后台手动处理已完成，图片质量评分不纳入项目，其他真实腾讯云数据万象能力后续独立确认。
7. 后台重复图提示。P1-11 已完成后台图片管理中的精确 SHA-256 重复提示；相似图推荐、相似图分组、以图搜图和自动去重后续独立确认。
8. sitemap、SEO 基础优化。P1-12 已完成动态 sitemap、动态 robots 和公开页面基础 SEO 元信息；搜索引擎提交、结构化数据、SEO 后台配置、AI 自动文案和图片 SEO/CDN 优化后续独立确认。
9. 用户中心、通知中心、互动排行榜、站点说明、版权说明、下架申请、隐私政策和用户协议；用户中心与通知中心已在 P1-7 完成基础切片，互动排行榜已在 P1-8 完成基础切片。
10. 高级搜索与资料增强：P1-15 已完成数据库内高级搜索，支持清晰度、来源、版权状态、人物同框、横竖图、水印状态等组合筛选；不接外部搜索引擎、不做以图搜图或相似图推荐。

### P2：第三阶段

1. 外部搜索增强：P1-15 已完成数据库内高级组合筛选；P2 如继续增强，重点转向搜索建议、热门搜索、后台搜索运营配置和外部搜索引擎接入。
2. Meilisearch 或 Typesense。
3. 以图搜图、以文搜图。
4. 相似图分组。
5. 微信小程序只读版：浏览、搜索、收藏、评论。
6. 投稿功能：普通用户提交图片素材、来源链接和必要说明；投稿后不公开，管理员审核通过并整理发布后才可公开。

## 5. 用户故事

1. 作为游客，我想按年份查看梅西图片，这样可以快速回到某个生涯阶段。
2. 作为游客，我想进入某场比赛的相册，这样可以按事件考古。
3. 作为普通用户，我想收藏图片，这样以后可以快速找回。
4. 作为普通用户，我想评论图片，这样可以参与讨论。
5. 作为普通用户，我想对图片补充信息或提交纠错，这样可以帮助编辑修正时间、来源、事件或人物信息。
6. 作为普通用户，我想举报不当评论，这样社区内容能被维护。
7. 作为支持者，我想通过赞助支持网站，这样站点能长期维护。
8. 作为支持者，我想显示支持者徽章，这样能表达我对项目的支持。
9. 作为普通用户，我想通过任务或纪念日获得并佩戴勋章，这样能留下参与网站的身份印记。
10. 作为编辑员，我想批量上传图片，这样能高效整理历史素材。
11. 作为编辑员，我想给图片选择分类子项（如赛事、球队、赛季、年份）和标签，这样前台用户能检索。
12. 作为编辑员，我想看到重复图和相似图提示，这样能减少图库污染。
13. 作为管理员，我想审核评论，这样能降低 UGC 风险。
14. 作为管理员，我想查看赞助订单和支付回调，这样能排查支付问题。
15. 作为管理员，我想查看图片点赞、评论、收藏和转发排行榜，这样能了解轻社交互动热度。
16. 作为管理员，我想管理勋章、获取任务和纪念日发放，这样能维护用户成长体系。
17. 作为管理员或编辑员，我想审核用户投稿，通过后再进入图片整理和发布流程，这样普通用户投稿不会直接公开。

## 6. 不做什么

第一版不做：

- 普通用户直接公开上传图片。
- 图片版权交易。
- 付费解锁原图。
- 完整论坛、私信、关注流。
- 自动识别梅西以外所有人物并自动发布。
- 微信小程序支付闭环。
- APP。
- 多语言。
- 商业图库授权。
- 通用 CMS 页面管理。

## 7. 验收标准

P0 完成时，应能做到：

- 管理员能上传并管理图片，批量上传后能进入上传批次进行批量整理。
- 首页能展示“最新照片”，包含最新发布的相册图片和单独上传图片。
- 前台用户能按相册、分类子项（含年份、球队、赛事等）和标签检索图片。
- 每张图片有来源和版权状态字段。
- 图片文件通过可配置存储管理；生产环境优先走 COS/CDN，本地存储仅作为开发或过渡方式。
- 后续 P1/P2 功能有清晰任务入口。
