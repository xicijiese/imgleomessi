本节“生产未部署”等为当日交付记录；用户随后已进行生产更新操作，但未提供完整验收结果，不推定已完成全部生产验收。

### 2.3 存储与图片处理

- Laravel 文件系统支持 local 和 COS 两种存储模式。
- local 使用 PHP GD 生成展示图和缩略图。
- COS 使用腾讯云数据万象生成展示图和缩略图。
- 展示图最大 2048×2048，缩略图最大 600×600，统一输出 WebP。
- 图片处理通过队列异步执行，不阻塞上传请求。
- 自动发布等待 metadata、hash 和最新派生图任务成功；缺少展示图或缩略图不能发布。
- COS 临时读写、派生图、SHA-256、相似候选和 OCR 按需链路已完成本地/测试验证。

### 2.4 分类安全、用户管理与档案共建者

- 系统保留 8 个主分类；生涯阶段、年份、场景是发布必选分类，其他 5 个主分类可选。
- 系统主分类和系统保留子分类不可删除。
- 普通子分类无图片、相册或子分类引用时可以删除；有引用时显示关联数量并阻止删除。
- 分类删除的并发外键异常会转换为页面通知，不再显示 Livewire 500。
- 档案共建者不开放公开申请、审核或取消申请，只由管理员在私域确认后授予。
- 管理员可以授予、编辑、公开/隐藏和撤销档案共建者资料。
- 授予普通用户共建者身份时，可获得 `editor` 内容角色。
- `editor` 只能管理图片、相册、分类和标签，不能进入用户、订单、支付、审核、系统设置等管理模块。
- `/supporters` 已分区展示运营守护者和档案共建者。
- 用户可在 `/settings/profile` 维护头像；管理员可在 `/admin/users` 代维护头像、治理角色与状态，并查询登录历史和操作审计。

### 4.3 用户、角色与共建者

| 身份 | 当前权限 |
|---|---|
| 普通用户 | 前台浏览、账号资料、普通互动和投稿资格申请；未获资格不能上传投稿 |
| `submitter` | 普通用户权限 + 私有投稿、查看本人记录、待审资料修改与撤回；不能进入后台 |
| `editor` | 普通用户权限 + 图片、相册、分类、标签维护、图片投稿审核；不能审批投稿资格 |

共建者资料只能由管理员在后台授予、编辑和撤销，前台不提供申请入口。
