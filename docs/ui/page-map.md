# 页面清单与 UI 映射

## 1. UI 原则

产品是内容密集型图库，不做营销型落地页。第一屏应直接让用户进入浏览、搜索和相册，而不是大段品牌宣传。

前台技术实现采用 Inertia.js + Vue 3 + TypeScript + Tailwind CSS。前台不使用重型后台组件库，优先定制图片卡片、筛选面板、相册头部、评论区等产品专属组件。

设计关键词：

- 内容优先
- 清晰检索
- 移动端友好
- 克制、资料库感
- 图片网格性能优先
- 轻社交不喧宾夺主

## 2. 全局导航

### Web 桌面端

- 顶部：站点名、搜索框、图库、时间线、专题、支持本站、登录头像。
- 搜索页/图库页：左侧筛选栏 + 右侧图片网格。
- 图片详情页：主图 + 信息侧栏 + 相似图片 + 评论。

### Web 移动端

- 顶部：站点名 + 搜索入口。
- 底部导航最多 5 项：首页、图库、搜索、收藏、我的。
- 筛选使用底部抽屉，不占满常驻空间。

### 小程序

- 首页
- 搜索
- 专题
- 收藏
- 我的

小程序不放复杂后台，不放批量上传，不优先放支付入口。

## 5. 核心组件

- 图片卡片：缩略图、标题、日期、相册、收藏按钮。
- 图片网格：支持懒加载、固定宽高比例、骨架屏。
- 最新照片模块：首页 P0 模块，展示最新发布图片；单独上传且不属于相册的已发布图片也应展示。
- 筛选面板：年份、球队、赛事、标签、清晰度、来源。
- 相册头部：封面、标题、事件日期、说明、统计。
- 图片详情信息栏：来源、版权状态、尺寸、标签、赛事、人物同框。
- 评论区：登录提示、输入框、评论列表、举报、审核状态。
- 支持者徽章：低调展示，不影响浏览。
- 图片灯箱：使用 PhotoSwipe。
- 专题轮播：使用 Swiper，限制在首页精选和专题页局部区域。

## 6. UI 质量要求

1. 图片列表必须避免布局跳动：缩略图区域必须有稳定宽高比。
2. 移动端触控区域不小于 44px。
3. 搜索和筛选必须有加载状态、空状态和错误状态。
4. 所有图片必须有 `alt` 文本，优先使用标题和事件信息。
5. 不使用表情作为结构性图标，使用 SVG 图标。
6. 评论、支付、上传等表单必须有明确错误提示。
7. 深层页面必须保留返回路径或面包屑。
8. 图片详情页不自动下载原图。
