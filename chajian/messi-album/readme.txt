引用独立图库公开相册，不下载图片、不创建媒体附件、不重复上传 COS。

== 安装 ==
1. 先部署图库的 WordPress 相册接口，生成专用只读令牌并配置图库令牌哈希。
2. 在 WordPress 的插件页面上传 messi-album.zip 并启用。
3. 打开设置→梅西图库相册，保存 HTTPS 图库域名和令牌，测试连接。
4. 在文章中打开图库相册窗口，粘贴“整个相册”分享链接，读取并选图。
5. 经典编辑器插入短代码；区块编辑器复制生成的短代码到短代码区块。

== 更新与限制 ==
已插入选图及顺序保存在本篇文章元数据中，图库新增图片不会自动加入。
已有引用通过下拉框重新读取，可调整说明和顺序；更新影响文章当前展示。
公开数据正常缓存5分钟，网络异常最多使用自上次成功核验起15分钟内的数据。
明确401/403/404/410会清除旧数据；无法核验且超期时隐藏相册。
整页缓存/CDN仍可能保留旧HTML，须另外设置刷新期限及下架清缓存流程。
单相册最多10000张；超限明确报错，不截断插入。
本版不支持GIF、原图下载、历史文章迁移、复制文章时自动迁移引用。
同一短代码不能直接复制到另一篇文章；请在目标文章重新创建相册引用。
停用插件不删除图片及文章引用，重新启用可恢复展示。

== 隐私 ==
仅WordPress服务端向配置的图库发送令牌和相册查询，访客从返回的图片域名加载图片。
无遥测，不请求其他外部服务。令牌不在前台输出，可使用MESSI_ALBUM_TOKEN服务端常量。
